Коротко: в AutoMetronom нет учётной записи, аналитики, рекламы и отслеживания. Звук с микрофона анализируется на вашем устройстве и никогда не записывается. Устройство покидают только запросы, описанные ниже. Политика действует во всех регионах; см. раздел для вашего региона.

Обработка данных

Для работы функций AutoMetronom обрабатывает следующую информацию:

  • Микрофон: звук анализируется на вашем устройстве для определения темпа, размера и первой доли. Ничего не записывается и не сохраняется, звук в реальном времени нам не передаётся.
  • Распознавание песен: чтобы распознать песню, короткий аудиоотпечаток (сигнатура, а не запись) отправляется в Shazam (Apple) через ShazamKit.
  • Поиск темпа: после распознавания название, исполнитель и, если есть, код ISRC отправляются в Deezer и GetSongBPM для поиска темпа. Личные идентификаторы не передаются.
  • Настройки и значения для песен: ваши настройки и сохранённые для песен значения хранятся только на вашем устройстве.

Хранение и удаление

Все данные остаются на вашем устройстве. Сохранённые значения можно сбросить в приложении, а удаление приложения стирает все локальные данные. AutoMetronom не использует iCloud и не имеет собственного сервера. Резервные копии, которыми управляете вы или Apple, могут содержать копии данных.

Сервисы

AutoMetronom бесплатно и не содержит покупок или подписок. Распознавание обеспечивает Apple (ShazamKit); темп запрашивается у Deezer и GetSongBPM, которые обрабатывают технические данные, например IP-адрес, по собственным политикам. Письма в поддержку используются только для ответа на обращение. Сайт размещён на GitHub Pages, который может обрабатывать технически необходимые данные доступа: IP-адрес, сведения о браузере и время обращения.

Региональная информация

Швейцария

По применимому швейцарскому закону о защите данных вы можете запросить доступ, исправление или удаление. Свяжитесь с нами по указанному адресу. Мы сами не собираем персональные данные; запросы по поиску касаются указанных третьих сторон.

Европейский союз и ЕЭЗ

Если применяется GDPR, обработка на вашем устройстве необходима для предоставления запрошенных вами функций. Распознавание и поиск темпа выполняются по вашему запросу и основаны на исполнении договора, а поиск — также на законном интересе в работоспособном приложении. Вы можете реализовать права по GDPR и обратиться в надзорный орган.

США

Мы не продаём и не передаём персональные данные и не используем их для рекламы или отслеживания. Жители некоторых штатов США могут запросить доступ или удаление письмом на указанный адрес.

Материковый Китай

AutoMetronom работает без учётной записи. Описанные запросы отправляются сторонним сервисам, которые могут находиться за пределами материкового Китая. Эти функции используются по вашему запросу; по вопросам конфиденциальности свяжитесь с нами.

Другие регионы

Мы сами не собираем персональные данные. По любым запросам свяжитесь с нами по указанному адресу; местные права зависят от применимого к вам законодательства.

Ваши права

Вы управляете данными прямо в приложении. По вопросам конфиденциальности пишите на support@canusing.com.
